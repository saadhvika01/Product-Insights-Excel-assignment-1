# Product-Insights-Excel-assignment-1
# 📊 Excel Product Dataset Analysis

#📌 Project Overview

This project demonstrates my foundational **Data Analysis skills using Microsoft Excel**. The objective was to explore a product dataset, perform basic statistical calculations, apply conditional logic, and extract useful information from text-based Product IDs.

The project focuses on essential Excel functions that are commonly used in data cleaning, exploration, summarization, and analysis.

This project is part of my **Data Analytics learning journey and portfolio development**.


#📂 Dataset

The dataset contains information about different products and includes the following attributes:

| Column           | Description                                                     |
| ---------------- | --------------------------------------------------------------- |
| Product ID   | Unique identifier containing date/month and country information |
| Product Name | Name of the product                                             |
| Brand Name   | Brand associated with the product                               |
| Price ($)    | Price of the product in USD                                     |
| Quantity     | Available quantity                                              |
| Category     | Product category                                                |

#Product Categories
The dataset contains products from categories such as:

* Electronics
* Fashion
* Kitchen
* Outdoor
* Beauty
* Sports
* and other product categories


#🎯 Objectives

The main objectives of this project were to:

* Explore and summarize the product dataset
* Calculate basic statistical measures
* Apply logical conditions using Excel
* Perform conditional aggregation
* Count products based on specific conditions
* Extract information from Product IDs
* Practice commonly used Excel functions for data analysis
